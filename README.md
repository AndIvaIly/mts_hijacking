# ИИ-консультант МТС Energytool

Чат-бот для сайта Energytool: по базе знаний подбирает клиенту продукт, задаёт уточняющие вопросы и передаёт менеджеру заявку с резюме диалога. Проект команды на хакатоне Hack&Change 2026.

**Состояние:** каркас репозитория. Кода решения ещё нет, стек не утверждён — см. [вопросы команде](docs/team-questions.md).

## Начало работы

Нужны Python 3.11+, `make` и git.

```bash
git clone https://github.com/AndIvaIly/mts_hijacking.git
cd mts_hijacking
make setup OWNER=ivan    # ivan | arthur | andrew: назвать себя и подключить git-хуки
make check               # линт и тесты должны быть зелёными
```

Материалы организаторов (база знаний, вопросы, регламент) положите в `data/` — каталог не попадает в репозиторий, подробности в [data/README.md](data/README.md).

## Как работаем

1. Решение записываем строкой в [decision log](docs/decision-log.md) — до кода.
2. `make lint`.
3. `make test`.
4. Ветка `<участник>/<тема>` → pull request в `main`.

Полные правила для людей и ИИ-агентов — [AGENTS.md](AGENTS.md).
