# data/ — локальные данные кейса

Сюда каждый участник кладёт материалы организаторов. Каталог в `.gitignore`: в репозиторий попадает
только этот файл. Публиковать исходные выгрузки запрещено условиями кейса (ограничение 1), а проверка
`make lint` не пропустит их в коммит.

Ожидаемое содержимое (имена как на платформе автопроверки):

| Файл | Что это |
| --- | --- |
| `knowledge-base.zip` | База знаний Energytool (Markdown) |
| `questions.csv` | Вопросы для локального прогона: колонки `id,question` (за основу — `demo_questions.csv`) |
| `demo_output.csv` | Образец ответов организаторов |
| `reglament.docx` | Технический регламент автопроверки |

`solution.py` на платформе читает входные файлы из каталога `DATA_DIR`, по умолчанию `data`.
